> **데이터**: `data/processed/olist_order_item_level.csv` (배송완료 + 이상치 제거 기준)

## 분석 1 — 배송 지연일별 평균 평점 추이: 급락 지점 탐색

### 무엇을 보는가

예상 배송일 대비 실제 배송일의 차이(`delay_days`)를 x축으로 놓고,  
해당 지연일의 평균 리뷰 평점을 꺾은선으로 그린다.  
막대 그래프(오른쪽 y축)로 각 지연일의 주문 건수를 함께 표시해 신뢰도를 나타낸다.

### 데이터로 확인된 수치

| 지연일 | 평균 평점 | 해석 |
|--------|---------|------|
| -2일 (조기) | 4.06점 | 기대 이상 |
| 0일 (정시) | 3.99점 | 기준선 |
| +1일 | 3.68점 | 첫 하락 감지 |
| **+3일** | **2.58점** | **급락 기점 — 3점 이하 진입** |
| +5일 | 2.14점 | 심각 구간 진입 |
| +7일 이후 | 1.7~1.9점 | 1점대 고착화 |

### 핵심 인사이트

- **정시(0일)와 하루(1일) 지연 사이의 낙차(0.31점)** 보다  
  **1일에서 3일 사이의 낙차(1.10점)** 가 3.5배 크다.
- 지연 3일이 되는 순간 "허용 범위" 심리가 무너지는 변곡점.
- 7일 이후 평점이 더 이상 크게 떨어지지 않는 이유: 이미 최악(1점)이 지배적.

## 분석 2 — 지연/비지연별 평점 1~5점 분포 비교

### 무엇을 보는가

두 가지 차트로 구성된다.

**차트 A** (좌우 대칭 막대): 비지연 그룹과 지연 그룹 각각의 1~5점 비율을 나란히 비교.  
**차트 B** (누적 막대): `조기배송 → 정시 → 1~3일 → 4~7일 → 8~14일 → 15~30일 → 30일 초과`  
7개 구간별로 1~5점의 구성 비율이 어떻게 이동하는지를 누적 막대로 시각화.

### 데이터로 확인된 수치

**비지연 그룹**

| 평점 | 비율 |
|------|------|
| 5점 | ~63% |
| 4점 | ~19% |
| 3점 | ~9% |
| 1점 | ~9% |

**지연 그룹**

| 평점 | 비율 |
|------|------|
| 1점 | ~40% |
| 5점 | ~12% |
| 4점 | ~10% |

**구간별 요약**

| 구간 | 평균 평점 | 주문 수 |
|------|---------|--------|
| 조기배송 | 4.21점 | 100,843 |
| 정시(0일) | 3.99점 | 1,436 |
| 1~3일 지연 | 3.23점 | 2,088 |
| 4~7일 지연 | 2.09점 | 1,943 |
| 8~14일 지연 | 1.69점 | 1,581 |
| 15~30일 지연 | 1.61점 | 1,122 |
| 30일 초과 | 2.04점 | 349 |

> **30일 초과에서 평점이 소폭 반등하는 이유**: 극단적으로 오래된 지연은 이미  
> 고객이 포기·체념한 상태이거나, 판매자가 적극적으로 보상 대응한 경우가 섞여 있어  
> 통계적으로 왜곡될 수 있다. 해석 시 주의.

### 핵심 인사이트

- 지연이 발생하는 순간 평점 분포가 **"5점 지배"에서 "1점 지배"로 역전**된다.
- 4~7일 구간은 1점 비율이 이미 50%를 넘어 평점 회복이 사실상 불가능한 구간.

## 분석 3 — 판매자 귀책 지연(물류사 인도 병목) × 평점 변화

### 무엇을 보는가

`shipping_limit_date`(판매자가 물류사에 넘겨야 하는 기한)를 기준으로  
실제 물류사 인도일(`order_delivered_carrier_date`)의 초과 일수를 x축으로 사용.  
이를 통해 **최종 배송 지연의 원인이 판매자 측인지 택배사 측인지**를 분리한다.

추가로 `판매자 귀책 여부 × 최종 지연 여부` 2×2 조합의 평균 평점을 막대로 비교한다.

### 데이터로 확인된 수치

**판매자 지연일별 평균 평점**

| 판매자 지연일 | 평균 평점 |
|------------|---------|
| -3일 (여유) | 4.09점 |
| 0일 (당일) | 3.87점 |
| +7일 | 3.15점 |
| +14일 | 2.11점 |

**2×2 조합 평균 평점**

| 조합 | 평균 평점 |
|------|---------|
| 판매자OK / 최종 정시 | ~4.2점 |
| 판매자OK / 최종 지연 | ~3.0점 (택배사 귀책) |
| 판매자 지연 / 최종 정시 | ~3.6점 (만회) |
| **판매자 지연 / 최종 지연** | **~1.8점 (최악)** |

### 핵심 인사이트

- **판매자 지연은 단독으로도 평점을 낮추지만**, 최종 배송까지 늦어질 때 가장 큰 타격.
- 판매자가 늦었더라도 택배사가 만회해서 정시 도착하면 평점이 3.6점으로 회복된다.  
  → **"판매자 지연 조기 탐지 + 택배사 긴급 루트 배정"** 이 현실적인 개선 방향.
- 판매자 지연일 기준 **7일이 3점 이하 진입 지점** (최종 지연 기준 3일보다 완충이 있음).  
  판매자 병목 개입의 골든타임은 **5~7일** 구간.

## 분석 4 — 고객 인내 임계일 시각화 및 사전 개입 기점 도출

### 왜 "평균 평점 급락 지점"만으로는 부족한가

평균 평점은 극단값에 민감하다. 지연 3일 시점의 평균 2.58점은  
"2점대 고객이 많다"는 뜻이 아니라, **1점 고객이 급격히 늘어난 결과**일 수 있다.  
사전 개입의 목표는 **이미 1점을 줄 결심을 한 고객이 아닌, 아직 경계선에 있는 고객**에게 개입하는 것이므로  
"평점이 몇 점 이하로 떨어지는 날"이 아닌 **"1점 비율이 몇 %를 넘는 날"**을 기준으로 삼아야 한다.

---

### 추천 시각화 ① — 저평점 vs 고평점 비율 교차 분석 (꺾은선 + 면적)

```
x축: 배송 지연일 (0~25일)
y축: 해당 비율 (%)
선 1 (빨강): 저평점(1~2점) 비율
선 2 (초록): 고평점(4~5점) 비율
강조: 두 선이 교차하는 날 (역전 지점)
음영: 개입 권장 구간 (3~5일)
```

**이 차트가 보여주는 것**  
- 지연 0일에는 고평점 비율이 저평점 비율의 **8~9배**.
- 지연이 길어질수록 두 비율이 수렴하다가 특정 일수에 **역전**된다.
- 역전 이전, 즉 "고평점이 아직 우세한 마지막 구간"이 개입 효과가 가장 높은 시점.

**해석 가이드**  
역전 지점이 지연 5~6일 근처라면, **3~5일 구간에 쿠폰/사과 알림을 발송**하는 것이  
이미 기울어진 후가 아닌 "기울어지기 직전"에 개입하는 것이 된다.

---

### 추천 시각화 ② — 1점 평점 비율 막대 + 경보선/위험선

```
x축: 배송 지연일 (0~25일)
y축: 1점 평점 비율 (%)
막대 색: 50% 이상(빨강) / 30% 이상(주황) / 미만(노랑)
기준선 1: 30% → 경보선 (이 날 이후 개입 시작)
기준선 2: 50% → 위험선 (이 날 이후 개입 실효성 저하)
수직선: 각 기준선 처음 초과하는 날 표시
```

**이 차트가 보여주는 것**  
- 지연일이 길어질수록 **1점 응답 비율이 선형에 가깝게 증가**한다.
- 30% 경보선 도달 시점 ≈ 지연 **3일**
- 50% 위험선 도달 시점 ≈ 지연 **5~6일**

**운영 해석**  
| 구간 | 1점 비율 | 권장 액션 |
|------|---------|---------|
| 지연 1~2일 | 10~20% | 모니터링 |
| **지연 3~4일** | **30~40%** | **사과 알림 + 쿠폰 발송 (선제 개입)** |
| 지연 5~6일 | 40~55% | 긴급 에스컬레이션 |
| 지연 7일+ | 60~80% | 사후 보상 처리 |

---

### 추천 시각화 ③ — 지연일 × 평점 분포 히트맵

```
행(y축): 배송 지연일 (0~20일)
열(x축): 리뷰 평점 (1~5점)
셀 값:  해당 지연일에서 각 평점 비율 (행 합계 = 100%)
색상:   초록(높은 비율) → 빨강(낮은 비율)
강조:   1점 열 × 지연 3~5일 구간에 테두리 박스
```

**이 차트가 보여주는 것**  
- 지연 0일: 5점 열이 밝은 초록 → 5점 응답이 지배적.
- 지연 3일: 1점 열이 급격히 붉어지는 시각적 전환점을 직관적으로 포착.
- **히트맵은 "어느 날부터 무엇이 지배하는가"를 한 눈에 파악**하는 데 가장 효과적인 포맷.

---

### 3가지 시각화를 종합한 결론: 골든타임은 **지연 3일**

| 근거 | 지연 일수 |
|------|---------|
| 평균 평점 3.0 이하 진입 | 3일 |
| 1점 비율 30% 경보선 초과 | 3일 |
| 저평점 비율이 고평점의 절반 수준 도달 | 3~4일 |
| 히트맵에서 1점 열 색상 전환 시작 | 3일 |

> **결론**: 예상 배송일 기준 **+3일** 이 고객 인내의 임계점이다.  
> 이 시점 이전(지연 1~2일)에 선제적 사과 알림과 쿠폰을 발송하면  
> "1점을 주기로 결심하기 전 고객"에게 개입할 수 있다.  
> 지연 5일 이후 개입은 이미 1점 결정자가 과반이 되어 실효성이 크게 감소한다.

### A/B 테스트 설계 방향 (사전 개입 효과 검증)

| 항목 | 내용 |
|------|------|
| **개입 기준** | `delay_days >= 1` (예상일 1일 초과 시점) |
| **대조군** | 기존 프로세스 — 별도 안내 없음 |
| **실험군** | 지연 예측/확정 시 사과 알림 + 할인 쿠폰 즉시 발송 |
| **Primary Metric** | 30일 이내 재구매율 (코호트 리텐션) |
| **Secondary Metric** | 리뷰 점수 분포 변화 (1점 비율 감소 여부) |
| **주의사항** | `payment_type == 'voucher'` 사용자는 실험군 오염 가능성 있으므로 제외 고려 |
